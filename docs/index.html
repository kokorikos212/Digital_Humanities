🔬 Agentic Ontological Discourse Analysis

An LLM-powered pipeline that autonomously maps conversational text to structured ontologies — RDF triples, semantic networks, and Obsidian knowledge graphs.

🔍 How It Works

🧠 Linguistic Parsing

spaCy-powered POS tagging, named entity recognition, and dependency tree parsing. Each token is annotated with lemma, morphology, and syntactic role.

🦉 RDF Triples

Extracted entities and relations are serialized into W3C-standard RDF (Turtle/JSON-LD) via rdflib with custom ontology vocabularies.

🕸️ Semantic Networks

Interactive pyvis network graphs with force-directed layout. Nodes represent ontological entities; edges represent typed relations.

📝 Obsidian Vault

Generated Markdown notes with YAML frontmatter and [[wikilinks]] for browsing the extracted knowledge graph in Obsidian's graph view.

📦 Output Schema

OntologicalAnalysis
├── analysis_id, source_text, source_corpus
├── linguistic_analysis  → tokens, entities, dependencies, noun_chunks
├── conversation         → speakers, utterances, reply_graph, pragmatics
├── ontology             → entities (rdf:type + properties), triples, prefixes
├── obsidian_notes       → generated .md files with [[wikilinks]]
├── visualizations       → paths to SVG / HTML artifacts
└── summary              → human-readable narrative
